# Диаграммы поведения «Трекера собеседований»

Лабораторная работа № 5. Вариант 47. Выполнил Лазарев Александр, группа ОИСТ-412.

## Варианты использования

Актор — соискатель. Граница системы охватывает управление откликами, встречи, подготовку, контакты HR, сводку и резервные копии. При создании и изменении отклика или встречи обязательна валидация полей (`include`). При удалении обязательно подтверждение. Напоминание (`extend`) появляется, если приложение открыто, встреча ещё не началась и до неё осталось меньше 24 часов.

## Диаграммы последовательности

| Сценарий | Что показывает | Файлы |
|---|---|---|
| Добавление собеседования | Проверку формы и сохранение. Первое собеседование переводит отклик из подходящего статуса в «Собеседование». | [PNG](sequence/01-create-interview.png) · [PlantUML](sequence/01-create-interview.puml) |
| Смена статуса отклика | Обновление истории и доски, обработку ошибки записи. | [PNG](sequence/02-change-status.png) · [PlantUML](sequence/02-change-status.puml) |
| Поиск и фильтрация | Поиск по компании и должности, вывод совпадений и пустого результата, сброс запроса. | [PNG](sequence/03-filter-applications.png) · [PlantUML](sequence/03-filter-applications.puml) |
| Удаление отклика | Подтверждение, отмену и удаление связанных встреч и задач. | [PNG](sequence/04-delete-application.png) · [PlantUML](sequence/04-delete-application.puml) |

Компоненты на диаграммах соответствуют [контроллеру интерфейса](../../app/js/main.js), [модели](../../app/js/model.js), [валидации](../../app/js/validate.js) и [модулю хранения](../../app/js/store.js). Данные сохраняются в `localStorage` браузера. Поисковый запрос живёт в состоянии интерфейса. Учебная реляционная модель лабораторной № 4 описывает другой проект, «Трекер полезных привычек».

## Повторный экспорт

Из корня репозитория, подставив путь к PlantUML:

```sh
java -jar /path/to/plantuml.jar -charset UTF-8 -tpng docs/use_case/use-case.puml docs/behavior/sequence/*.puml
java -jar /path/to/plantuml.jar -charset UTF-8 -tsvg docs/use_case/use-case.puml
```
