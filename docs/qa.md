## Как повторить

Запуск из корня репозитория:

```sh
python3 -m http.server 8000 --directory app
```

Откройте http://localhost:8000 в чистом профиле браузера и выполните сценарии из таблицы. Проверку переполнения можно воспроизвести в изолированном тестовом профиле, имитируя ошибку записи. Для автоматических проверок используйте Node.js 22+:

```sh
npm test
```

В GitHub Actions эти же тесты запускаются на Pull Requests и при изменениях в `main`. Они проверяют бизнес-логику, формат хранения, отрисовку, наличие файлов стартовой страницы и синтаксис JavaScript.
